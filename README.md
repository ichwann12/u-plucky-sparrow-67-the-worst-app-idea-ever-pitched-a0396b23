One sentence, at most 240 characters, pitching the worst and most useless
app idea imaginable. `main.ts` reads the entry from `entry.txt` and writes
it to `entry.txt` in the output directory.

## Entry

> Introducing Napkin: an app that photographs your lunch, rates how photogenic it is, and then charges you for the privilege of eating it cold.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```
